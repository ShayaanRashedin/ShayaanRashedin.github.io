Linux Systems Programming

SyncWire

C++20Linux / POSIXTCP SocketsConcurrency

A Linux client-server application for resumable file uploads and incremental directory synchronization over TCP.

Engineering Highlights

  • Designed binary message framing and handled partial socket reads and writes.
  • Combined an epoll accept loop with a bounded worker pool and coordinated shutdown.
  • Recovered interrupted uploads with CRC-32 checks, fsync, and atomic file replacement.

Systems & networking foundation: Operating-system interfaces, thread coordination, protocol design, and filesystem durability.

Scope: One-way push MVP with loopback binding. HMAC authentication does not encrypt file data.

NetWatch

C++20Linux procfsTCP / UDPSQLite

A Linux agent that connects TCP/UDP socket activity to processes and exposes event history through a live dashboard.

Engineering Highlights

  • Mapped IPv4/IPv6 sockets to owning processes using Linux procfs.
  • Tracked connection changes and stored events through a bounded queue and background writer.
  • Delivered a read-only REST API, dashboard, tests, and systemd/container configuration.

Systems & networking foundation: Linux process visibility, network troubleshooting, asynchronous persistence, and service delivery.

Scope: Periodic host snapshots; process visibility depends on Linux permissions. Alerts are investigation signals.

Network Threat Detector

PythonCSV ParsingSQLiteAirflow

A Python command-line tool that analyzes traffic logs, flags suspicious patterns, and saves findings for review.

Engineering Highlights

  • Parsed custom and Wireshark-exported CSV logs through a modular CLI.

Scope: Analyzes exported logs. Rule-based findings do not establish malicious activity.

Embedded Systems & Robotics

EEBOT Robot Guidance

HCS12 AssemblyGPIO / ADCState MachinesInterrupts

A COE538 group project implementing tape following, junction decisions, and route backtracking on an eebot mobile robot.

Engineering Highlights

  • Integrated five infrared channels, bumper inputs, and motor control through hardware registers.
  • Organized navigation with a finite-state machine and fixed-size route memory for backtracking.
  • Used timer interrupts and LCD feedback to support motion timing, calibration, and debugging.

Embedded systems foundation: Assembly programming, register-level hardware interfaces, sensor processing, interrupt timing, and state-based control.

Team: Shayaan Rashedin, Hamidullah Mohmmad Ali, and Daniel Chylek — COE538, Toronto Metropolitan University.

Scope: Branching tape mazes with up to 32 recorded junctions or corners. Route memory lasts one run; automatic stopping at the starting area assumes a blank end to the tape.
