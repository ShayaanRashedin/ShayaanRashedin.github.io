Linux Systems Programming

SyncWire

C++20Linux / POSIXTCP SocketsConcurrency

An authenticated Linux client-server application for reliable, resumable file transfer and incremental directory synchronization over TCP.

Engineering Highlights

  • Designed a custom binary protocol with explicit message framing, bounded payloads, request IDs, and correct handling of partial socket reads and writes.
  • Combined an epoll accept loop with a bounded connection queue and configurable std::jthread worker pool.
  • Implemented HMAC-SHA256 peer authentication, CRC-32 integrity checks, restart recovery, fsync, and atomic file replacement.
  • Validated protocol, filesystem, authentication, concurrency, and recovery behavior with CTest, real TCP acceptance tests, sanitizers, and GitHub Actions.

Systems & networking foundation: Linux/POSIX interfaces, concurrent network services, protocol design, recovery, and filesystem durability.

Scope: One-way push MVP with loopback binding. HMAC authentication does not encrypt file data.

Linux Network Observability

NetWatch

C++20Linux procfsTCP / UDPSQLite

A Linux observability agent that correlates TCP/UDP sockets with owning processes, detects behavioral patterns, persists event history, and exposes data through a REST API and dashboard.

Engineering Highlights

  • Parsed Linux procfs data to correlate IPv4/IPv6 TCP and UDP sockets with process IDs, users, executables, and command lines.
  • Separated collection from transactional SQLite persistence through a bounded producer-consumer queue and background writer.
  • Applied explainable behavioral detection rules and exposed events, alerts, and evidence through a read-only JSON REST API and JavaScript dashboard.
  • Delivered Catch2/CTest coverage, GitHub Actions, Docker configuration, systemd services, installation checks, and CPack release packaging.

Systems & networking foundation: Linux process and socket visibility, concurrent processing, behavioral detection, persistence, and service delivery.

Scope: Periodic host snapshots; process visibility depends on Linux permissions. Alerts are investigation signals.

Embedded Systems & Robotics

EEBOT Robot Guidance

HCS12 AssemblyGPIO / ADCState MachinesInterrupts

Embedded robot-navigation firmware developed in HCS12 Assembly, integrating infrared sensors, GPIO, ADC, motor control, timer interrupts, and finite-state navigation.

Engineering Highlights

  • Integrated five infrared sensor channels, bumper inputs, motor direction and enable signals, and a 20×2 LCD through register-level hardware interfaces.
  • Organized tape following, junction decisions, dead-end recovery, and backtracking with a finite-state machine and fixed-size route memory.
  • Used timer-overflow interrupts, interrupt service routines, calibrated sensor thresholds, and live LCD feedback to support motion timing and hardware debugging.
  • Connected instruction-level firmware to physical sensors and actuators on the HCS12 / MC9S12 eebot platform using CodeWarrior.

Embedded systems foundation: Firmware, register-level programming, sensor processing, interrupt timing, robotics validation, and hardware-software integration.

Team: Developed as a three-person COE538 project at Toronto Metropolitan University by Shayaan Rashedin, Hamidullah Mohmmad Ali, and Daniel Chylek.

Scope: Branching tape mazes with up to 32 recorded junctions or corners. Route memory lasts one run; automatic stopping at the starting area assumes a blank end to the tape.

Network Threat Detector

PythonCSV ParsingSQLiteAirflow

A Python command-line tool that analyzes custom and Wireshark-exported network logs, flags suspicious patterns, and saves structured findings for review.

Engineering Highlights

  • Separated CSV ingestion, detection rules, presentation, SQLite persistence, and workflow orchestration into focused modules.
  • Implemented explainable rules for possible port scanning, suspicious outbound connections, exfiltration indicators, and beaconing.
  • Automated repeatable execution with Bash and an optional Apache Airflow DAG backed by a local Docker Compose workflow.

Security automation foundation: Network log analysis, modular Python, deterministic detection, persistent records, and repeatable workflows.

Scope: Analyzes exported logs rather than live packet capture. Rule-based findings do not establish malicious activity.
