Cybersecurity Homelab

A controlled home lab used to practice cybersecurity operations from both offensive and defensive perspectives. The lab includes a Kali attacker VM, a Metasploitable2 target VM, and an Ubuntu/Splunk SIEM VM where applicable.

What I Practiced

  • Network reconnaissance with Nmap, service enumeration, and banner review.
  • OpenVAS/GVM vulnerability scanning and vulnerability triage.
  • Metasploit exploit validation in an isolated ethical lab environment.
  • CVE documentation, risk notes, and remediation recommendations.
  • Splunk brute-force detection, alert logic, and log analysis as the blue-team extension of the lab.

Evidence Preserved

  • VM screenshots for Kali, Metasploitable2, and Splunk/Ubuntu.
  • Nmap and OpenVAS evidence pages and report files.
  • Metasploitable2 exploit validation screenshots.

Featured Project 2

Network Threat Detector

PythonNetworkingTraffic AnalysisWireshark CSVDetection LogicReports

A practical security tool that analyzes network-related data and detects suspicious activity using Python, rule-based logic, and alert/report generation. This project connects cybersecurity, programming, networking, and data workflow concepts.

Technical Focus

  • Python development for parsing and analyzing network/log-style data.
  • Wireshark CSV support for traffic-analysis workflows.
  • Rule-based detection logic for suspicious patterns and security-relevant events.
  • Alert and report generation to turn raw network data into reviewable findings.
  • Basic data engineering concepts through structured inputs, processing, and output artifacts.

Recruiter-Relevant Value

  • Shows ability to build a security-focused tool rather than only use existing tools.
  • Demonstrates networking knowledge, traffic/log analysis, and practical detection thinking.
  • Supports SOC/security analyst learning through repeatable detection and reporting workflows.
  • Can be extended with workflow orchestration if implementation evidence is added later.
