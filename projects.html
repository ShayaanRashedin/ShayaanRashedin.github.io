Featured Software Project

Network Threat Detector

PythonCLICSV ParsingSQLiteAirflowBash

A Python IDS-style detection prototype that analyzes traffic logs, supports custom and Wireshark CSV formats, applies rule-based detection logic, prints readable alerts, saves findings to SQLite, and includes Apache Airflow orchestration.

Engineering Value

  • Separates parsing, detection rules, alert printing, and database writes into focused Python modules.
  • Uses command-line arguments for file path and log format selection.
  • Persists alert records in SQLite so findings can be reviewed after execution.
  • Includes Bash automation and an Airflow DAG to show repeatable workflow execution.
  • Connects software development with security-domain logic such as port scans, suspicious outbound connections, exfiltration indicators, and beaconing.
