Featured Project

Network Threat Detector

Python IDS-style prototype that analyzes network traffic logs, applies practical detection rules, prints analyst-readable alerts, and stores findings for review.

Project Overview

Security detection logic built with Python, CSV parsing, SQLite, and Airflow.

PythonWireshark CSVSQLiteAirflowBashDetection Rules

Network Threat Detector is a practical security tool that reads traffic logs, normalizes fields, runs rule-based detections, prints alerts, and saves alert records to a local SQLite database. It connects cybersecurity analysis with software development and data workflow concepts.

Current Capabilities

  • Parses custom CSV traffic logs.
  • Supports Wireshark exported CSV logs.
  • Detects possible port scanning behavior.
  • Detects suspicious outbound connections to external IPs on uncommon ports.
  • Detects possible data exfiltration based on outbound byte volume.
  • Detects possible beaconing through repeated connections at regular intervals.
  • Stores alerts in SQLite for review after execution.

Code Structure

  • main.py handles CLI arguments, log loading, detection execution, and alert persistence.
  • detector/log_reader.py parses custom and Wireshark CSV formats.
  • detector/rules.py contains the detection rules and thresholds.
  • detector/alert_printer.py formats alerts for terminal review.
  • detector/database.py creates and writes to the SQLite alerts database.
  • airflow/dags/network_threat_detector_dag.py schedules the detector with Apache Airflow.

Detection Rules

The project currently includes four core detections: possible port scan, suspicious outbound connection, possible data exfiltration, and possible beaconing behavior.
